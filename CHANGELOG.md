## [1.0.0] - 2026-10-18
First public build (Android APK).

### Added
- Timer that starts when the phone is laid face-down and stops when it is lifted; stopwatch, Pomodoro (25/5, 50/10, 52/17, 90/20) and Flowtime modes; calibratable flip sensitivity.
- Plan: 10-minute daily grid with an auto-planner.
- Study: subjects, topics, exams with countdown, weekly targets, syllabus coverage.
- Flashcards with spaced repetition (FSRS or SM-2), cloze deletions, reverse and image cards, text import.
- Stats: totals by subject, streaks, heatmaps, best hours, focus quality, weekly review, yearly calendar, manual session editing.
- Offline focus sounds, Do Not Disturb while focusing, reminders, six home screen widgets, 7 languages.
- Local SQLite storage with daily JSON backup to a chosen folder; no account, no ads, no network permission.
